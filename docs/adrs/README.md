# Architecture Decision Records (ADRs)

Hier stehen die wichtigen Entscheidungen des Projekts: Kontext, Entscheidung und Konsequenzen.
Die ADRs selbst sind auf Englisch geschrieben.
Eine akzeptierte ADR wird nicht umgeschrieben. Ändert sich etwas, entsteht eine neue ADR, und die
alte bekommt den Status „Superseded by NNNN“.

Format: `NNNN-kurzer-titel.md` mit Status, Context, Decision, Consequences.
